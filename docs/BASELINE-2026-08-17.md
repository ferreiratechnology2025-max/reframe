## Arquitetura Atual

```
Lead (name, niche, city, phone, place_id, lead_id)
   │
   ▼
resolve_archetype(niche) ── fail-fast se nicho não mapeado (ARCHETYPE_NOT_SUPPORTED)
   │
   ▼
generate_proposal_with_fallback(trusted_business)      [llm_provider.py]
   │   • ollama | gemini | agnes (PRIMARY_LLM / FALLBACK_LLM)
   │   • 3 tentativas + retry temp 0.3→0.0 → fallback de provedor
   │   • prompt com regras B2C + EVIDENCE_INTEGRITY
   ▼
_evidence_integrity_gate(proposal)                      [validate_evidence_integrity.py]
   │   • bloqueia publicação se LLM distorceu fato verificável
   │   • severidade high/critical → EVIDENCE_INTEGRITY_FAIL
   ▼
Aplicação do Arquétipo Determinístico                    [config/archetypes.py]
   │   • proof = trust_signals, primary_color, hero_image (TRAVADOS)
   ▼
Render premium.html (Jinja2 + Tailwind CDN + inline styles)  [templates/premium.html]
   │
   ▼
publish_to_r2(proposal, html) → https://{ROOT_DOMAIN}/{slug}   [publisher.py]
```

**API:** `api/app.py` (FastAPI) — leads_db/generations_db em memória, rotas `/api/leads`, `/api/generations`, `/api/r2/test`. Pipeline roda em BackgroundTasks via `api/pipeline_adapter.py` (classificação de erro por código estável + retry inteligente).

## Riscos Conhecidos

1. **Tailwind via CDN** — landing depende de runtime externo; sem build step para templates.
2. **Google Places nunca exercitado contra API real** — só mocks.
3. **Store em memória** (`leads_db`/`generations_db`) — reset a cada deploy.
4. **Sem config de pytest** (pytest.ini/pyproject) — defaults.
5. **Rede:** `files.pythonhosted.org` com falha SSL no ambiente → usar mirror (aliyun) para instalações.
6. **`api/requirements.txt` ainda presente** — redundante com a fonte única.

## Decisões de Design para VS-0

1. Tokenizar o arquétipo: `config/archetypes.py` passa a referenciar tokens em vez de cores hardcoded.
2. `engines/design_tokens.py` + `engines/visual_policy.py` + `engines/positioning.py`.
3. `gates/design_token_gate.py` + `gates/rendered_visual_gate.py` (playwright já validado).
4. Template migra de inline styles para CSS variables derivadas dos tokens.
5. Reutilizar padrões existentes: gate (evidence integrity), error codes, Pydantic trust boundary, harness de testes.

## Como reproduzir

```powershell
# 1. Criar e ativar venv
python -m venv .venv
.\.venv\Scripts\activate

# 2. Instalar dependências (usar mirror se files.pythonhosted.org falhar)
pip install --index-url https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com -r requirements.txt

# 3. Browsers playwright
python -m playwright install chromium

# 4. Testes
python -m pytest tests/

# 5. Frontend
cd ai-ui-shell && npm install && npm run build
```
